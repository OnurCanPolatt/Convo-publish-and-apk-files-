# Convo-publish-and-apk-files-
Bu proje .net9 blazor hybrid projeside signalr teknolojisi kullanarak geliştirmiş olduğum sohbet uygulamasıdır.İçerisinde signalr ile mesajlaşma,minio ile dosya transferi ve janus(webrtc)) teknolojisi ile video konferans özelliği mevcuttut.Aynı zamanda profil oluşturup düzenleyebilme,sohbetleri silebilme,grup oluşturup sohbet edebilme mevcuttur.Aşağıda apk dosyası,uygulamanın docker imaj linki,mobil ve browser uygulama içi görüntüler mevcuttur.
Android Mobil Apk v1.0 indir: https://github.com/OnurCanPolatt/Convo-publish-and-apk-files-/releases/tag/v1.0
Web / Backend Docker image görüntüle: https://hub.docker.com/repositories/onurcanpolat
